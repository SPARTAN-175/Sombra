PROTOCOLO: SOMBRA v0.2

Juego táctico top-down para móvil.
200 misiones generadas y verificadas.

CONTROLES:
1. Selecciona ALFA/BRAVO/CHARLIE/DELTA.
2. MOVER: toca el mapa para dar una posición.
3. ATACAR: selecciona un operador y toca un enemigo.
4. CUBRIR: ordena movimiento y activa cobertura.
5. SIGILO: movimiento lento y menos exposición.
6. ESPERAR: cancela la orden del operador.
7. EJECUTAR: pausa/reanuda el tiempo táctico.
8. Completa el objetivo y lleva a los supervivientes a EXTR.

Instalación: sube todo a la raíz de GitHub Pages y usa Instalar aplicación en Chrome.
